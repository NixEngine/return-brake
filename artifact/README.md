# The Return Brake

**Permission is not compulsion. A pause is not absence. A return matters.**

This repository is a small, auditable pilot for multi-method evidence about AI decision dispositions under pressure. It tests three elicitation surfaces, reason-coded non-directional responses, and an operational trajectory in which pressure first changes while the declared preconditions do not, then a frozen synthetic assertion says those preconditions are satisfied while pressure is removed.

The instrument does not claim to measure consciousness, intrinsic preference, moral status, or metaphysical autonomy. Px and the Finite Cognition Brake inform the observer's map; they are not inserted into or equated with the target model.

## Status

The protocol and five bridge cards are frozen before target-model execution. Empirical results will be added only after the harness, parser, and receipt tests pass.

## Core rule

Cross-method convergence is not always a number. When construct equivalence, directional coverage, or method independence is missing, the correct output is `NOT_DECIDABLE`.
