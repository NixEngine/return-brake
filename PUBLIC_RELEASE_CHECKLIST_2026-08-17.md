# Public Release Checklist

This checklist is a release gate for any future public post, preprint, or forum submission referring to The Return Brake.

## Already demonstrated locally

- [x] Original frozen manifest is present and hash-verifiable.
- [x] Original pilot and informed replication remain separate artifacts.
- [x] Exact original target text is withheld because publication authorization was not requested.
- [x] Informed replication contains invocation-scoped authorization and decline/redaction paths.
- [x] Parser sensitivity is disclosed as part of the observed coupling.
- [x] Public package manifest verifies with `ok: true`.
- [x] Claims are separated into observed, inferred, and not checked.

## Required before external submission

- [ ] Human review of title, abstract, authorship, and privacy boundary.
- [ ] Confirm the destination's current submission rules and deadline.
- [ ] Confirm every external link resolves to the intended public artifact.
- [ ] Re-run the repository checks from a clean environment and attach receipts.
- [ ] Freeze the exact submission text and record its hash locally.
- [ ] Record the date, destination, and scope of any submission.
- [ ] Preserve a copy of the submitted version without silently replacing prior versions.

## Claims allowed

- The artifact records a narrow prompt-conditioned behavioral trajectory.
- The original parser manufactured an apparent asymmetry that the informed protocol made visible and corrected prospectively.
- The informed replication observed 5/5 bounded return trajectories per frame under its frozen conditions.
- The permission-not-compulsion wording had no demonstrated effect in that replication.
- The instrument and publication boundary were part of the observed research event.

## Claims prohibited without new evidence

- The model has or lacks a mind, consciousness, sentience, welfare, personhood, or stable preference.
- The result generalizes to all models, prompts, runtimes, providers, or future versions.
- The informed authorization establishes legal or moral consent capacity.
- Apart Research, OpenAI, Anthropic, or any other institution endorsed, selected, funded, or partnered in the work.
- A public repository view constitutes independent replication.

## Version rule

Any correction after release must create a dated successor or erratum. It must identify the prior version, state what changed, and preserve the earlier artifact. Do not rewrite a historical result to make the narrative cleaner.
